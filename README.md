# 今天吃什么 · 中餐家常菜 Web

这是一个无需前端构建依赖的在线 Web 应用，可直接部署到任意静态托管平台。

## 本地运行

需要 Node.js 20 或更高版本：

```bash
npm run dev
```

浏览器打开 `http://localhost:4173`。

## 在线部署

仓库已包含以下平台配置：

- GitHub Pages：`.github/workflows/pages.yml`
- Netlify：`netlify.toml`
- Vercel：`vercel.json`

站点使用的是相对资源路径，也可以直接拖放到任意静态网站托管服务。
