# 数据来源

本目录中的结构化菜谱由以下开源项目生成：

- 项目：HowToCook
- 仓库：https://github.com/Anduin2017/HowToCook
- 许可证：Unlicense
- 导入提交：`a2d45c6984dff9ee941da0e7c452f7965965d962`

导入时排除了 `dishes/template` 模板目录，共生成 372 道有效菜谱。

- `recipes.js`：浏览器直接加载的完整数据
- `recipes.json`：便于检查和二次处理的 JSON 数据
- `import-report.json`：导入数量、分类统计、缺少菜谱图片的文件清单
